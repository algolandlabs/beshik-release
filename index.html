beshik

A self-hosted PaaS for one server. The same binary is the server and the command-line client.

Debian and Ubuntu

curl -fsSL https://algolandlabs.github.io/beshik-release/key.asc | sudo gpg --dearmor -o /etc/apt/keyrings/beshik.gpg
echo "deb [signed-by=/etc/apt/keyrings/beshik.gpg] https://algolandlabs.github.io/beshik-release/apt stable main" | sudo tee /etc/apt/sources.list.d/beshik.list
sudo apt update && sudo apt install beshik

Fedora, RHEL and others with dnf

sudo curl -fsSLo /etc/yum.repos.d/beshik.repo https://algolandlabs.github.io/beshik-release/rpm/beshik.repo
sudo dnf install beshik

macOS and Linux with Homebrew

brew install algolandlabs/beshik/beshik

snap (the client only)

sudo snap install beshik

Set up a server

sudo beshik init

Then point two DNS records straight at the server: *.<root> and *.dev.<root> (A, and AAAA with IPv6). No proxy or CDN in front: with Cloudflare, set them to "DNS only".

Upgrading

sudo apt update && sudo apt upgrade beshik     # Debian, Ubuntu
sudo dnf upgrade beshik                         # Fedora, RHEL
brew upgrade beshik                             # Homebrew

On a server the package restarts beshik on the new version; running apps keep serving.
